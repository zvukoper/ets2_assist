## Processes and ports
telemetry: game/plugin -> WebSocket/REST `localhost:8080`; API includes `/api/ws/delta/flat/?throttle=50` and `/api/rest/single/frame/paused`.
web_static: Python/overlay HTTP server `localhost:8082`; serves `data/`.
app_http: GUI HttpListener `localhost:8083`; CORS enabled.
app_ws: GUI WebSocketSharp `localhost:8084`; commands + track upload.
legacy: `Ets2Telemetry.exe` is disabled; `ets2-telemetry-server.dll` is not required by the current startup path.

## Data flow
map: `web_pda_map.html` -> telemetry 8080; commands/save 8084; trigger/targets 8083; static assets 8082.
hybrid: `web_ui_hybrid.html` -> telemetry 8080; commands 8084; `web_data.json` via static server.
telemetry_state: map uses `data/js/state.js`; hybrid uses `data/js/hybrid_ui_state.js`; both must update fuel/headOffset on every snapshot/delta.
static_map: `GeoJson/roads.geojson`, `GeoJson/cities.geojson`, `localized_cities/cities_sibirmap.json`, `Overlays.json`.
targets_read: `GET http://localhost:8083/custom_targets.json` -> AppDataPaths.CustomTargetsFile; never read mutable targets from static `data/`.
targets_write: `POST http://localhost:8083/update_targets` with JSON array; server wraps `{customTargets:[...]}`.
ui_visibility: GUI checks pause/focus every 500 ms; sends `show_ui_first`, `show_ui`, `hide_ui` over 8084.

## Track save contract
request: client sends `{format:"compact_v2", data, meta, mapData, customTargets, requestId}` to 8084.
commands: `save_trail`, `start_recording`, `stop_recording`, `reset_recording_origin`, `add_random_target`, `remove_random_target`, `reset_target_reached`, `show_ui_first`, `show_ui`, `hide_ui`, `play_sound`.
guards: save only after actual ETS2 pause confirmation; duplicate `requestId` must not create a second track.
response: `{status:"ok"|"error", message, requestId}`.
compact: first line metadata JSON; trail `<t>;<x>;<z>;<heading>;<speed>`; data `D;...;<headOffset>`; events `E;...`.
headOffset: six numbers; index 3 is normalized heading 0..1.

## Rules
version: `MAJOR.MINOR.PATCH-DESCRIPTION-YYYY.MM.DD-HHmm`; every functional change increments PATCH; synchronize BuildInfo.cs, project VersionPrefix, web badges, `data/web_runtime_manifest.json`, `data/ets2_assist_build.txt`, and playback build log.
source_of_truth: edit root `data/`; publish is generated output; do not use publish as the only source.
release: `dotnet publish -c Release`; verify EXE and `publish/data` after publishing.
cache: preserve stable overlay URLs; invalidate changed local assets through existing cache/version mechanism.
compatibility: preserve ports, REST paths, WebSocket commands and compact track format unless plan explicitly changes a contract.
logging: use existing Logger/AppendLog; log requestId and data-flow failures; do not silently hide new errors.
window: save/restore bounds with `Screen.DeviceName`; clamp to current working area if monitor is absent.
