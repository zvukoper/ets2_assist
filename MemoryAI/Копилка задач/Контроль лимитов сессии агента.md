Дата: 31.08.2026. Автор: пользователь. Обновлено 10.09.2026 (источник истины — `ollama_parsed_usage.txt`).

## Правила (v1, эксперимент)

1. **Каждые ~10 минут** работы агента — замер Session usage.
   **Источник истины:** `D:\repo\ets2_assist\MemoryAI\ollama_parsed_usage.txt`
   (строка 1 = процент с запятой, строка 2 = время до RESET). Файл обновляется расширением
   `ets2assist.ollama-usage-monitor` каждые 5 секунд — всегда свежие данные.
   **НЕ использовать** `ollama_usage_v2.bat` / `ollama_login.bat` / `data\ollama_usage.ps1`
   для проверки лимитов — устаревший путь.
2. **> 90%** — агент ОСТАНАВЛИВАЕТ выполнение новых задач и ПРЕДУПРЕЖДАЕТ пользователя
   (выводит процент + предлагает упростить/разбить задание).
3. **> 97%** — ПОЛНАЯ ПАУЗА:
   - сохранить контекст (`/memories/session/*`) и MemoryAI (INSTRUCTIONS/WORKLOG);
   - сгенерировать текст коммита (git commit message) по текущим изменениям;
   - корректно завершить сессию (не начинать новых правок).
4. Процент — первой задачей в TODO каждой сессии; прогрессбар — в резюме после публикации.

## Механика для агента (ОБНОВЛЕНО 10.09.2026)

- **Инструмент:** читать `MemoryAI\ollama_parsed_usage.txt`.
  - PowerShell: `$txt = Get-Content 'D:\repo\ets2_assist\MemoryAI\ollama_parsed_usage.txt'; $pct = $txt[0]; $reset = $txt[1]`
  - В агенте: `read_file('D:\repo\ets2_assist\MemoryAI\ollama_parsed_usage.txt')` — первые 2 строки.
- Таймер агент отслеживает сам (по времени последнего замера; перед КАЖДОЙ новой
  задачей/этапом — если прошло ≥10 мин — замерить заново).
- Если файл пуст / содержит `UNKNOWN` / `0,0` — расширение выключено или куки протухли.
  Скажи пользователю: «Включи расширение `ets2assist.ollama-usage-monitor` в VS Code,
  или перезапусти VS Code и войди в ollama.com в Edge-профиле расширения». **НЕ запускай
  `ollama_login.bat` сам** — он интерактивный и блокирует терминал.

## Устаревшие пути (НЕ использовать для контроля лимитов)

- `D:\repo\ets2_assist\ollama_usage_v2.bat` — headless Edge + `--dump-dom`. Заменён
  расширением VS Code, оставлен для отладки.
- `D:\repo\ets2_assist\ollama_login.bat` — открывает Edge для логина. Только для ручной отладки.
- `D:\repo\ets2_assist\data\ollama_usage.ps1` — низкоуровневый парсер HTML. Парсер расширения
  пишет напрямую в `ollama_parsed_usage.txt`.
