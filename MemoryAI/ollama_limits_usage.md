## Правила учёта (см. MemoryAI/INSTRUCTIONS.md)

- ПЕРЕД любой задачей — план TODO; первый пункт = контроль лимитов + прогноз.
- Формат прогноза: `Текущий ресурс: NN.N% RESET hh. Прогноз: ~NN% через ~hh мин.`
- Проверять лимиты ДО задачи и ПОСЛЕ; в долгих — каждые ~5 мин; пороги 90% / 95%.
- После задачи — запись в РАЗДЕЛ 3 (прогноз И факт — для будущих переоценок).
- Вывод проверки: `SESSION: NN.N | RESET: <время до сброса>`.
- **ЛОГИКА РЕСУРСА (01.09.2026, задача пользователя): основной ресурс = ПРОЦЕНТЫ.
  100% = конец (агент отключается); продолжение — только после RESET (обнуление до 0%).
  Порядок прогноза:
  1) Хватает ли ПРОЦЕНТОВ: `старт% + расход ≤ 95%` → работаем (время вторично);
  2) НЕ хватает → если RESET наступит ЗА время задачи → работаем (ресурс восстановится
     в середине);
  3) Ни процентов, ни RESET → ПРОБЛЕМА: разбить задачу / отложить до сброса /
     спросить пользователя. Достигать 100% на середине задачи НЕЛЬЗЯ.**
- После задачи — запись в РАЗДЕЛ 3 (прогноз И факт — для будущих переоценок).

### Выводы переоценки

1. **Прогнозы завышены в 4–8 раз** (напр. прогноз 24% → факт 1.5%; 35% → 1.9%;
   60% → 5.6%). Причина: оценка «по объёму задачи», а фактический расход идёт
   по числу итераций диалога; одна итерация ≈ 0.5–2%.
2. **Время — самый стабильный прогноз** (±30%); расход % сильно зависит от того,
   сколько итераций потребовал фикс.
3. **Публикация стоит ~0.5–1%** — она не должна быть причиной отказ от задачи.
4. **Полная сессия** (v39.4–v39.11, 6 ч, 15+ задач) = ~16–17% — а не 80–90%.
5. **Пороги предупреждения** остаются: 90% предупреждение, 95% стоп.
6. Правило прогноза: `прогноз = сумма классов задач × 1.3 (запас)` — если сумма
   с текущим % > 90 → предупредить пользователя / разбить задачу.

### Выводы переоценки 05.09.2026 (дополнение)

1. **deepseek-v4-flash тратит ещё меньше, чем в переоценке 01.09:** средний факт
   по 12 задачам 04–05.09 — лёгкая ~0,5%, средняя ~1,5%, крупная ~3,3%. Прогнозы
   завышены в 2–6 раз даже по уточнённым оценкам 01.09.
2. **Крупные задачи с итерациями** (2+ republish, фиксы ловушек сборки) — единственный
   класс, где расход заметно выше: 4–7% (SDO 03.09 = 9,8% на glm5.3, но на deepseek
   ~2–4,7%).
3. **Правило прогноза для deepseek:** `прогноз = сумма классов × 1.5 (запас)` —
   но даже с запасом факт обычно ниже. Для типовой задачи 1–2 итерации достаточно
   прогноза 0.5–2%.
4. **RESET 35м при 4,3%** — ресурс в норме, запас большой; можно работать без
   опасений прерваться.
